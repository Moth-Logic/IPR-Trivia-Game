# Título #

# Descripción #
- Este proyecto está desarrollado con Python. Y tiene una parte de Interfaz Gráfica y otra de lógica para darle funcionalidad al juego. El juego consta de una serie de preguntas que deberás ir respondiendo correctamente. Es multijugador por lo que el que haya respondido la mayor cantidad de preguntas será el ¡ganador! ¡Buena Suerte!
